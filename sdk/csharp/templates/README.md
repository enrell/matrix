# Matrix C# node: <NAME>

Generated by `scaffold.sh` (ML1). Generic test component speaking
`matrix.component/0.1`: echo, chained dependency calls, resources,
streams, events, cancel. Same contract as `docs/ML1-NODE.md`; no
product application. SDK sources are vendored under `src/`; the build
needs only the .NET SDK (>= 10), no NuGet packages.

## Layout

- `node/Program.cs` — the component (`dotnet build -c Release`).
- `src/` — vendored SDK (`Matrix.Component`: component + operator).
- `config.json` — managed-service config template (fill in paths and
  the operator fingerprint, then serve).
- This README — the recipe.

## 1. Build (offline, no packages)

```sh
dotnet build -c Release node/
```

Framework-dependent: runs with the installed .NET runtime via the
`dotnet` host baked into `config.json` at scaffold time.

## 2. Configure the operator (authority lives here, not in the node)

Edit `config.json`: private `home`, one component entry per logical
id (`prov`, `cons`, `indep`), `grants` mapping the operator
certificate fingerprint (`matrix-managed fingerprint
pki/client.der`) to components and capabilities, explicit
`outbound_grants` for consumers (requested is never granted), and
`tls` (dev PKI via `scripts/dev-pki.py` of the Matrix repo; never
weaken mTLS for demos).

## 3. Serve and compose

```sh
/path/to/matrix-managed serve config.json
```

Or from C# (no CLI quoting):

```csharp
await using var kernel = await Kernel.StartAsync(
    "/path/to/matrix-managed", config,
    new OperatorPki { Ca = ca, Cert = cert, Key = key });
var act = kernel.Client.Activate("prov", 20000);
var v = kernel.Client.Invoke(act["lease"].GetString()!,
    act["fence"].GetString()!, "op-1", "prov.echo@1",
    new Dictionary<string, object?> { ["ping"] = 1 });
// DisposeAsync reaps only this daemon.
```

`Kernel.Attach()` instead of `StartAsync()` connects to a shared
kernel; closing the attachment never stops it.

## 4. Test and withdraw

- Ungranted capability or bad lease: denied with a stable code
  (`permission-denied`, `stale-generation`), never dispatched.
- Withdraw: `Release` the lease, remove/re-provision the component
  (new generation, old refs stay dead), re-`Activate`.
- Crash path: kill the node process mid-`sleep_ms` call; the invoke
  terminal is not-ok and re-issuing the same operation never
  auto-replays an unknown effect.

## 5. Cleanup

Stop the daemon (SIGTERM/SIGINT; owned kernels via
`DisposeAsync()`), remove the private `home` directory. Leases are
credentials: do not paste them into reports.

## 6. Diagnose

```sh
dotnet run -c Release --project /path/to/SelfTest -- --doctor /path/to/matrix-managed
```

(Environment diagnosis as JSON; the SelfTest project also runs the
SDK suites. Paths point at the SDK checkout or staged copy.)
