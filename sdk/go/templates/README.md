# Matrix Go node: <NAME>

Generated by `scaffold.sh` (ML1). Generic test component speaking
`matrix.component/0.1`: echo, chained dependency calls, resources,
streams, events, cancel. Same contract as `docs/ML1-NODE.md`; no
product application. SDK sources are vendored under `mx/`; the build
needs only the Go toolchain (>= 1.24), no network.

## Layout

- `node.go` — the component (package main; `go build -o mx-node .`).
- `mx/` — vendored SDK (`component.go`, `operator.go`).
- `config.json` — managed-service config template (fill in paths and
  the operator fingerprint, then serve).
- This README — the recipe.

## 1. Build (offline)

```sh
GOPROXY=off go vet ./... && GOPROXY=off go build -o mx-node .
```

## 2. Configure the operator (authority lives here, not in the node)

Edit `config.json`: private `home`, one component entry per logical
id (`prov`, `cons`, `indep`) with entrypoint `./mx-node`, `grants`
mapping the operator certificate fingerprint
(`matrix-managed fingerprint pki/client.der`) to components and
capabilities, explicit `outbound_grants` for consumers (requested is
never granted), and `tls` (dev PKI via `scripts/dev-pki.py` of the
Matrix repo; never weaken mTLS for demos).

## 3. Serve and compose

```sh
/path/to/matrix-managed serve config.json
```

Or from Go (no CLI quoting):

```go
kernel, _ := mx.Start("/path/to/matrix-managed", config, mx.OperatorPKI{CA: ca, Cert: cert, Key: key}, "")
act, _ := kernel.ClientOf().Activate("prov", 20000, 0)
v, _ := kernel.ClientOf().Invoke(act["lease"].(string), act["fence"].(string),
    "op-1", "prov.echo@1", map[string]any{"ping": 1}, 0)
kernel.Close() // owned: reaps only this daemon
```

`Attach()` instead of `Start()` connects to a shared kernel;
closing the attachment never stops it.

## 4. Test and withdraw

- Ungranted capability or bad lease: denied with a stable code
  (`permission-denied`, `stale-generation`), never dispatched.
- Withdraw: `Release` the lease, remove/re-provision the component
  (new generation, old refs stay dead), re-`Activate`.
- Crash path: kill the node process mid-`sleep_ms` call; the invoke
  terminal is not-ok and re-issuing the same operation never
  auto-replays an unknown effect.

## 5. Cleanup

Stop the daemon (SIGTERM/SIGINT; owned kernels via `Close()`),
remove the private `home` directory. Leases are credentials: do not
paste them into reports.

## 6. Diagnose

```sh
go run ./cmd/matrix-doctor --binary /path/to/matrix-managed
```

(Environment diagnosis as JSON; paths point at the SDK checkout or
staged copy.)
