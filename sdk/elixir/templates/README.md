# Matrix Elixir node: <NAME>

Generated by `scaffold.sh` (ML1). Generic test component speaking
`matrix.component/0.1`: echo, chained dependency calls, resources,
streams, events, cancel. Same contract as `docs/ML1-NODE.md`; no
product application. SDK sources are staged under `lib/`; the build
needs only Elixir >= 1.17 with OTP >= 27 (`:json` is stdlib), no Hex
packages, no network.

## Layout

- `lib/` — staged SDK (`Matrix.Component`, `Matrix.CallCtx`,
  `Matrix.Handler`, `Matrix.Operator`, `Matrix.Doctor`, `Matrix.Node`).
- `mx-node` — the component escript (`MIX_ENV=prod mix escript.build`).
- `run-node.sh` — launcher wrapper (puts OTP's `escript` on PATH via
  absolute staged paths; same-machine validation).
- `config.json` — managed-service config template (fill in paths and
  the operator fingerprint, then serve).
- This README — the recipe.

## 1. Build (offline)

```sh
MIX_ENV=prod mix escript.build
```

## 2. Configure the operator (authority lives here, not in the node)

Edit `config.json`: private `home`, one component entry per logical
id (`prov`, `cons`, `indep`) with entrypoint `./run-node.sh`,
`grants` mapping the operator certificate fingerprint
(`matrix-managed fingerprint pki/client.der`) to components and
capabilities, explicit `outbound_grants` for consumers (requested is
never granted), and `tls` (dev PKI via `scripts/dev-pki.py` of the
Matrix repo; never weaken mTLS for demos).

## 3. Serve and compose

```sh
/path/to/matrix-managed serve config.json
```

Or from Elixir (no CLI quoting):

```elixir
kernel = Matrix.Operator.start("/path/to/matrix-managed", config, opki)
act = Matrix.Operator.activate(kernel.client, "prov", 20_000)
v = Matrix.Operator.invoke(kernel.client, act["lease"], act["fence"],
  "op-1", "prov.echo@1", %{"ping" => 1})
Matrix.Operator.close(kernel) # owned: reaps only this daemon
```

`Matrix.Operator.connect/4` instead of `start/4` attaches to a shared
kernel; closing the attachment never stops it.

## 4. Test and withdraw

- Ungranted capability or bad lease: denied with a stable code
  (`permission-denied`, `stale-generation`), never dispatched.
- Withdraw: `release` the lease, remove/re-provision the component
  (new generation, old refs stay dead), re-`activate`.
- Crash path: kill the node process mid-`sleep_ms` call; the invoke
  terminal is not-ok and re-issuing the same operation never
  auto-replays an unknown effect.

## 5. Cleanup

Stop the daemon (SIGTERM/SIGINT; owned kernels via
`Matrix.Operator.close/1`), remove the private `home` directory.
Leases are credentials: do not paste them into reports.

## 6. Diagnose

```sh
mix run -e 'Matrix.Doctor.main()' -- --binary /path/to/matrix-managed
```

(Environment diagnosis as JSON; paths point at the SDK checkout or
staged copy.)
