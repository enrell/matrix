# Matrix JS node: <NAME>

Generated by `matrix-scaffold` (ML1). Generic test component speaking
`matrix.component/0.1`: echo, chained dependency calls, resources,
streams, events, cancel. Same contract as `docs/ML1-NODE.md`; no
product application. Plain JS needs no TypeScript compiler;
`index.d.ts` ships types for TS users (JS and typed TS are distinct
supported entries over this same SDK).

## Layout

- `node.js` — the component (run one process per logical id).
- `config.json` — managed-service config template (fill in paths and
  the operator fingerprint, then serve).
- This README — the recipe.

## 1. Install the SDK (isolated, offline)

```sh
npm install --offline --no-audit --no-fund /path/to/matrix-component-*.tgz
```

`node.js` requires `matrix-component`: wire protocol plus the
operator surface. Zero dependencies. Node >= 20.

## 2. Configure the operator (authority lives here, not in the node)

Edit `config.json`: private `home`, one component entry per logical
id (`prov`, `cons`, `indep`) with entrypoint `node.js`, `grants`
mapping the operator certificate fingerprint
(`matrix-managed fingerprint pki/client.der`) to components and
capabilities, explicit `outbound_grants` for consumers (requested is
never granted), and `tls` (dev PKI via `scripts/dev-pki.py` of the
Matrix repo; never weaken mTLS for demos).

## 3. Serve and compose

```sh
/path/to/matrix-managed serve config.json
```

Drive the same flow from JS (no CLI quoting):

```js
const { start } = require("matrix-component");
const kernel = await start("/path/to/matrix-managed", configDict, operatorPki);
const act = kernel.client.activate("prov", 30000);
const v = kernel.client.invoke(act.lease, act.fence, "op-1",
  "prov.echo@1", { ping: 1 });
await kernel.close(); // owned: reaps only this daemon
```

`connect()` instead of `start()` attaches to a shared kernel;
closing the attachment never stops it.

## 4. Test and withdraw

- Ungranted capability or bad lease: denied with a stable code
  (`permission-denied`, `stale-generation`), never dispatched.
- Withdraw: `release` the lease, remove/re-provision the component
  (new generation, old refs stay dead), re-`activate`.
- Crash path: kill the node process mid-`sleep_ms` call; the invoke
  terminal is not-ok and re-issuing the same operation never
  auto-replays an unknown effect.

## 5. Cleanup

Stop the daemon (SIGTERM/SIGINT; owned kernels via
`await kernel.close()`), remove the private `home` directory.
Leases are credentials: do not paste them into reports
(`matrix-doctor` redacts).

## 6. Diagnose

```sh
npx matrix-doctor --binary /path/to/matrix-managed
```

Reports binary shape, versions, socket permissions and isolation
prerequisites as JSON. Failing fields carry actionable messages.
