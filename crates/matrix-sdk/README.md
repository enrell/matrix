# matrix-sdk

Legacy generic Matrix daemon client over a Unix socket
(`rpc`, `invoke`, `emit`, `status`). Frozen compatibility surface —
new integrations must use the managed profile instead
(see `docs/API-CATALOG.md`).

Status: `0.1.0` experimental — no `1.0` stability promise
(see `docs/VERSIONS.md` in the repository).
