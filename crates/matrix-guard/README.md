# matrix-guard

Linux sandbox spawn and supervision budget for
[Matrix](https://github.com/enrell/matrix): namespaces, seccomp,
rlimits and restart backoff.

Status: `0.1.0` experimental — no `1.0` stability promise
(see `docs/VERSIONS.md` in the repository).
