# matrix-host

Local process host for [Matrix](https://github.com/enrell/matrix):
process spawn, sessions, `matrix.component` dispatch and supervision.

Status: `0.1.0` experimental — no `1.0` stability promise
(see `docs/VERSIONS.md` in the repository).
