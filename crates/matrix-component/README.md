# matrix-component

Rust component SDK for [Matrix](https://github.com/enrell/matrix):
handshake, registration, activation, calls, dependencies and resources
over `matrix.component/0.1`.

Status: `0.1.0` experimental — no `1.0` stability promise
(see `docs/VERSIONS.md` in the repository).

License: MIT OR Apache-2.0 (`LICENSE-MIT`, `LICENSE-APACHE-2.0`).

Same observable contract as the other language SDKs
(see `docs/ML1-NODE.md`, `docs/ML1-MATRIX.md`).
