# matrix-runtime

Managed Matrix service: SQLite ledger, mutual TLS, leases, routes and
reconciliation, plus the public `matrix_runtime::api` facade — the only
supported integration surface alongside `matrix-component`
(see `docs/API-CATALOG.md`).

Status: `0.1.0` experimental — no `1.0` stability promise
(see `docs/VERSIONS.md` in the repository).
